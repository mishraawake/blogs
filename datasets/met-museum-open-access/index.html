Met Museum Open Access

The Metropolitan Museum of Art's entire collection — ~492,000 objects, full metadata, high-resolution images — released to the public domain.

Maintained byThe Metropolitan Museum of Art
ReleasedFebruary 2017 (continuously updated)
Size~492,000 object records; CSV file ~290 MB
LicenseCC0 1.0 Universal (public domain dedication)
FormatsCSV (bulk), JSON (per-object via REST API)
Includes images?Yes — for the public-domain subset (about 80% of objects)
API rate limit80 requests / second, no auth required

What's in it

Every catalogued object in the Met's collection — paintings, sculpture, textiles, weapons, musical instruments, photographs, drawings, prints, costumes, decorative arts — exposed as a structured record. Each row has more than 50 fields: object ID, title, culture, period, artist, medium, dimensions, credit line, geographic origin, and where in the museum it lives. For roughly 80% of objects flagged "Public Domain," the full-resolution image is also released as CC0 and can be downloaded and reused without attribution.

Why it's unusual

Most museum APIs are partial, watermark images, or restrict re-use. The Met went the other direction: full collection, full metadata, full-resolution images, no attribution required, no commercial restriction. The CSV is a flat file you can grep. The API is unauthenticated. The license is the strongest open license that exists. For a 150-year-old institution holding objects valued in the billions, that's a uniquely radical commitment to open data.

How to access

Bulk download (CSV): the canonical source is the metmuseum/openaccess repo on GitHub. Clone or download:

curl -O https://github.com/metmuseum/openaccess/raw/master/MetObjects.csv

REST API: for one-off lookups or live queries. No API key.

# List all object IDs (paginated, ~492k total)
curl https://collectionapi.metmuseum.org/public/collection/v1/objects

# Fetch a single object — Van Gogh's "Wheat Field with Cypresses"
curl https://collectionapi.metmuseum.org/public/collection/v1/objects/436535

# Search for "Vermeer"
curl "https://collectionapi.metmuseum.org/public/collection/v1/search?q=vermeer"

API docs: metmuseum.github.io

What people have built with it

  • Google Arts & Culture's high-resolution zoom interfaces ingest Met images directly.
  • Researchers have used the dataset for studies on color trends across centuries, geographic provenance of objects, and gender representation among catalogued artists.
  • Generative artists have built training pipelines on the public-domain image subset.
  • Hobby visualizations include every Met object plotted on a map by its culture's origin, and a year-by-year timeline of acquisition.
  • Educational tools that mix Met records with Wikidata to enrich artist biographies.

Worth knowing

  • Not every record has an image — "is public domain" and "has primary image" are separate columns. Filter on both.
  • The CSV updates weekly; the GitHub repo is the source of truth.
  • Some fields are highly sparse (e.g., Artist Wikidata URL exists but is often blank).
  • Object dimensions are free-text, not numeric — parsing requires regex if you want comparable numbers.
  • The Met's API does not return image binaries themselves; the JSON includes URLs to images hosted on images.metmuseum.org.
